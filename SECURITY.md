# Security status

This repository contains an unimplemented architecture and protocol draft.
No release is approved for public or security-critical use.

Report concerns through an authorized private channel to the repository owner.
Do not include secrets, identity documents, live exploit targets, or real reader
data in an issue. No public security contact, response SLA, or bounty is currently
established.

Before a public pilot, obtain independent review of identity enrollment,
authorization evaluation, JWS parsing, credential approval binding, signing key
isolation, transparency and witness integration, control-state completeness,
recovery, and verification copy. Complete the acceptance gates in
[ROADMAP.md](docs/ROADMAP.md). Documentation checks do not satisfy these gates.

Before public release, establish a security reporting contact, response ownership,
supported-version policy, dependency update process, incident communication plan,
and an owner-approved license for any published material.
